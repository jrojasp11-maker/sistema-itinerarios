\section{Arquitectura del Sistema}
% ============================================================

\subsection{Visi�n General}

El sistema sigue una arquitectura de \textbf{microservicios} con patr�n
\textbf{hexagonal} (Puertos y Adaptadores). Cada microservicio se divide en tres capas:

\begin{description}
  \item[Dominio (\texttt{domain/})] Contiene las entidades, puertos (interfaces),
        servicios y excepciones. Es puro Python sin dependencias externas.
  \item[Infraestructura (\texttt{infrastructure/})] Implementa los puertos:
        adaptadores HTTP, repositorios SQLAlchemy, clientes HTTP.
  \item[API (\texttt{api/})] Expone los endpoints REST mediante FastAPI.
\end{description}

\subsection{Enfoque}

Se aplicaron las siguientes t�cnicas:

\begin{enumerate}
  \item \textbf{Pruebas de unidad}: Cada clase y funci�n se prueba de forma aislada.
  \item \textbf{Dobles de prueba}: Se implementaron \textit{fakes} para sustituir
